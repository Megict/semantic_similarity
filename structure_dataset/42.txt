1. Цель работы.  
"Рассматривается тактический уровень управления группами РТК, предлагается использовать аналитико-синтетический сценарно-модульный подход к синтезу моделей тактики действий при планировании боестолкновений в виде альтернативных модулей-сценариев, состоящих из набора модулей боевых эпизодов, которые, в свою очередь, состоят из модулей элементарных действий."

2. Проблема, решаемая в работе.  
"Проблемным вопросом при управлении РТК является отсутствие экипажа, обладающего необходимым боевым опытом, навыками слаженности действий, способностью осуществлять продуманные, осознанные поступки, правильно понимать и реагировать на приказы командира. Это существенно усложняет работу командира по управлению и делает необходимым, с одной стороны, повышать уровень автономности PTK, а с другой – осуществлять заблаговременную (до начала боя) разработку возможных, сообразно ожидаемых условий, вариантов тактики действий PTK."

3. Разработанные в работе методы и алгоритмы.  
- "Суть аналитико-синтетического сценарно-модульного подхода при планировании тактики действий PTK состоит в разработке плана боя в виде базового сценария, включающего набор отдельных боевых эпизодов (модулей), в совокупности составляющих тактику действия PTK при выполнении поставленной боевой задачи."  
- "Формализованное описание задачи синтеза тактики действий РТК при групповом применении можно представить следующим образом. Имеется группа РТК, назначенная на выполнение некоторой боевой задачи Z в предполагаемых условиях тактической обстановки Sr, включающей сведения о своих ресурсах P (P ⊂ Sr ), объектах противника Ц (Ц ⊂ Sr ) и среде боевых действий R (R ⊂ Sr ). Известны типовые боевые эпизоды E = {E j } и составляющие их действия D = {Dk }, образующие в совокупности состав возможных сценариев C = {C i } выполнения поставленной боевой задачи."  
- "Фрагмент алгоритма управления тактикой действий истребителей в групповом воздушном бою имеет следующий вид: «ЕСЛИ имеет место дуэльная ситуация (ДС: курсовые углы цепей |q| ≤ 15⁰, углы визирования цепей |φ| ≤ 15⁰) и истребители находятся в сомкнутом боевом порядке (БПС), и имеют управляемые ракеты с радиолокационными головками самонаведения средней дальности (УРсРГССД), и бортовые радиолокационные станции (БРЛС) противника работают в режиме «захват», и высота истребителей не превышает 5 км ( H ≤ 5 км) и дальность истребители - противник меньше максимальной дальности пуска ракет противником ( Д V= л ≤ Д УРмакл ) или обнаружен пуск ракет противником, ТО целесообразно применить тактический маневр (ТП) «тактический отворот»."

4. Результаты, полученные в работе.  
- "Предложенный аналитико-синтетический сценарио-модульный подход ориентирован на моделирование событий, которые можно разложить на модулиальные, каждый из которых, в свою очередь, может быть смоделирован отдельно в соответствии с их функциональной направленностью, структурной целостностью и иерархичностью содержания."  
- "Данный подход особенно актуален при организации боевых действий с применением РТК поскольку позволяет посредством простых моделей и управляющих программ, описывающих элементарные действия, создавать более сложные модели поведения роботизированных систем на разных уровнях иерархии управления и проводить на этих моделях экспериментальные проверки и опытные исследования редких и уникальных событий, не имеющих достаточной репрезентативной статистики наблюдений."  
- "Таким образом, применимость аналитико-синтетического сценарио-модульного подхода для синтеза тактики действий РТК обусловлена: – возможностью декомпозиции боевых действий на отдельные элементы – модули в виде боевых эпизодов и составляющих их действий, из которых впоследствии можно будет формировать нужные, сообразно боевым условиям, варианты тактики действий РТК; – удобством синтеза программ управления РТК как на исполнительном (параметрическом), так и на поведенческом (организационном) уровнях в зависимости от уровня информационной (ситуационной) осведомленности о боевой обстановке; – реальностью разнообразить тактику действий РТК и свести до минимума шаблонное поведение за счет высокой комбинаторики модульной конструкции вариантов применения."

5. Используемые в работе метрики.  
"Необходимо с учетом целевой установки (показателя эффективности выполнения боевой задачи) WZZ(WZ → Z ), сведений о тактической обстановке Sr, известных типовых боевых эпизодов E и составляющих их действий D сформировать наилучший C* из возможных сценариев C вариант выполнения группой РТК поставленной боевой задачи Z в виде тактического решения Ur(C → Ur ), при котором обеспечивается достижение максимума целевой установки WZ с учетом заданной системы ограничений (Qi(СUr ), Qs, Qz, QD, Qmz )."
