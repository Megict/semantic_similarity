1. **Цель работы**  
   - "В статье на основе использования методов нечеткой логики и регрессионного анализа предложена методика, позволяющая оценивать страховые риски при страховании объектов и компаний с информационными инфраструктурами, а также определять параметры, наибольшим образом влияющие на значения риска, а также облегчает проведение альдеграйтинга."

2. **Проблема, решаемая в работе**  
   - "В чем проблемы такого медленного развития этого вида услуг? По мнению сотрудников компании СМП Страхование [4] причины следующие:  
     - проблемы с построением и оценкой модели риска;  
     - дефицит компетенций в области IT страхования;  
     - недостаток специалистов по определению и урегулированию страховых случаев;  
     - сложный и дорогостоящий андеррайтинг - оценка рисков ИБ."

3. **Разработанные в работе методы и алгоритмы**  
   - "алгоритм определения факторов, наибольшим образом влияющих на значение риска, с использованием данных из совокупности, получаемой с помощью продукционных правил, реализуется следующим образом.  
     Определяются продукционные правила для пяти входных, описанных выше, переменных (факторов): EP, IP, PE, UT, IS.  
     Все входные переменные по результатам экспертных оценок оцениваются по своим шкалам как на качественном уровне, так и, соответственно, в количественном виде в интервале от 0 до 1."  
   - "Предлагается в качестве демонстрации методики рассмотреть пример с пятью лингвистическими переменными с тремя интервалами значений по каждой из них. Для получения корректного результата вычисления риска параметры выбираются так, чтобы при росте значения каждого из них страховой риск для всех либо возрастал, либо уменьшался."  
   - "Уровень риска предлагается представлять в виде функции  
     𝑅= 𝑅 (𝐸𝑃, 𝐼𝑃, 𝑃𝐸, 𝑈𝑇, 𝐼𝑆),    (1)  
     значение которой предлагается вычислять, используя методы нечеткой логики [9]."

4. **Результаты, полученные в работе**  
   - "Вычисляя коэффициент множественной детерминации для оценки совместного влияния указанных пяти факторов на значение риска (равняется 0,7266), получаем, что 72,66% значения риска объясняется параметрами, включенными в уравнение регрессии."  
   - "Ранжирование в порядке убывания стандартизованных коэффициентов показывает, что наименьшее влияние на общее значение риска оказывает фактор - уровень защищенности от внутреннего нарушителя (IP). Для упрощения дальнейшего решения нашей задачи исключаем его из рассмотрения."  
   - "Предложенная методика по оценке страховых рисков в области информационных технологий предоставляет возможность страховым компаниям:  
     - относительно легко по сравнению с другими вышеупомянутыми методиками определять уровень риска в условиях неопределенности и облегчать андеррайтинг;  
     - на основании полученной оценки уровня риска принять решение о целесообразности страхования данного объекта информационной инфраструктуры, размере страховой премии и уровню покрытия страховых рисков;  
     - выработать рекомендации для страхователя с целью проведения мероприятий по снижению рисков информационной безопасности;  
     - оценивать риски страхования не только небольших компаний, но и компаний со сложными сетевыми информационными инфраструктурами."

5. **Используемые в работе метрики**  
   - "Коэффициент множественной детерминации для оценки совместного влияния указанных пяти факторов на значение риска (равняется 0,7266), получаем, что 72,66% значения риска объясняется параметрами, включенными в уравнение регрессии."
