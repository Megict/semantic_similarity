1. **Цель работы**  
   "Конечной целью анализа является формулирование рекомендаций по решению указанных выше проблем."

2. **Проблема, решаемая в работе**  
   "При реализации систем автоматического регулирования и компьютерном моделировании проявляется ряд сугубо практических проблем, естественно, не нашедших должного места в теории. К таким проблемам, обсуждаемым в данной работе, относятся: выбор величины горизонта прогнозирования при управлении нелинейным объектом, отсутствие для восприятия специалистами инженерного уровня доказательства возможности использования нелинейного матричного уравнения Риккати вместо решения системы уравнений необходимых условий минимума квадратического критерия качества, проблема статической ошибки в линейных системах, обеспечение запаса устойчивости системы и проблема статической настройки регуляторов (выбор заданных значений и зоны нечувствительности для переменных состояния)."

3. **Разработанные в работе методы и алгоритмы**  
   - "Основная особенность предлагаемого метода прямого доказательства состоит в предварительной замене вектора множителей Лагранжа формулой связи Λ = 2PX, которую легко получить из равенства функции Гамильтона вариационного метода и метода динамического программирования."  
   - "Предложен способ получения уравнения Риккати для вариационного метода Эйдера–Лагранжа. Дается более простое, доступное решение для понимания метода модификации критерия оптимальности с доказательством леммы о независимом пути метода динамического программирования Беллмана."  
   - "Предлагаются два способа устранения статической ошибки таких систем."

4. **Результаты, полученные в работе**  
   - "В результате анализа вариационного метода оптимизации управления нелинейным объектом сделан вывод о целесообразности задания горизонта прогнозирования небольшой длительности с использованием только первого значения управления как наиболее точного из вычисляемой последовательности значений."  
   - "Показано, что обычно принимаемое утверждение о равенстве нулю (или стремлении к нему) регулируемой величины в конце интервала управления оказывается неверным в случаях отсутствия интегральной составляющей в замкнутой системе регулирования."  
   - "Исследовано влияние на запас устойчивости весового коэффициента при управлении в квадратичном критерии качества. Предложена формула оценки наилучшего значения веса."

5. **Используемые в работе метрики**  
   "Весовая матрица Q1 меры ошибки H = XᵀQ₁X + qu² для квадрата регулируемой величины x₁² равна Q₁ = [1 0; 0 0], а при выборе второго веса q проведем предварительное исследование, задавая ряд значений q = 0,15; 0,25; 0,5; 1,0; 2,0."
